# Mystery Reseller

Starter app structure for researching eBay mystery boxes, estimating deal economics, tracking inventory, and preparing items for resale.

## Run
npm install
npm run dev

## Planned production integrations
- eBay official APIs for authorized search/listing workflows
- Auth + database
- AI vision for item identification and resale estimates
- Marketplace fee/shipping calculations
- Listing generation and publishing
- Stripe subscriptions

The eBay buttons intentionally hand the user off to eBay. They do not auto-purchase.
